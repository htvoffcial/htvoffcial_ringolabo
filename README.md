# りんごジュース実験室（Ringo Labo）

リンゴジュースにいろいろな薬品を入れる実験を、Android アプリの中で安全にシミュレーションするアプリです。

> ⚠️ これは画面の中だけの仮想実験です。実際の飲み物に薬品を入れたり、混ぜたものを飲んだりしないでください。強い酸・アルカリなどの試薬は現実では絶対に扱わないでください。

## できること

- ビーカーの中のリンゴジュース（200mL、pH 3.6）に薬品を1タップずつ入れる
- pH・温度・液量・泡・にごりがリアルタイムに変化し、液の色も変わる
- かき混ぜる / 加熱 / リセット、実験ログ表示

### 普通の試薬
クエン酸、重曹、紫キャベツ液（指示薬）、BTB液（指示薬）、フェノールフタレイン液（指示薬）、ヨウ素液、デンプン液、石灰水、炭酸水、お湯、砂糖、食塩、鉄粉

重曹を酸に入れると発泡し、指示薬を入れると pH に応じて液の色が変わります。

### 組み合わせ反応（v2.1で追加）
試薬同士の反応も再現します。ログには反応式も表示されます。

- ヨウ素液＋デンプン液 → ヨウ素デンプン反応で青紫色に
- 石灰水＋二酸化炭素（重曹の発泡・炭酸水）→ 白濁（Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O）
- 硫酸銅＋水酸化ナトリウム → 青い沈殿 Cu(OH)₂、さらにアンモニア水を加えると溶けて濃青色（テトラアンミン銅(II)イオン）
- 鉄粉＋硫酸銅 → 置換反応（Fe + CuSO₄ → FeSO₄ + Cu）、鉄粉＋強い酸 → 水素が発生
- 硝酸銀＋食塩 → 白い沈殿（Ag⁺ + Cl⁻ → AgCl↓）
- 過マンガン酸カリウム＋過酸化水素水 → 紫色が脱色して酸素が発生
- 強い酸と強いアルカリの中和では、中和熱（約57 kJ/mol）の発熱を再現
- 状態表示に水素イオン濃度 [H⁺] = 10^-pH mol/L を追加

### 劇薬・強めの試薬（仮想のみ）
硫酸、硝酸、塩酸、水酸化ナトリウム、過酸化水素水、アンモニア水、硫酸銅、硝酸銀、過マンガン酸カリウム

強い酸・アルカリを混ぜると中和による発熱・発泡が再現され、警告レベルが上がります。硝酸では液が黄色っぽく変色します。

## ビルド方法

Android SDK（platform 34 / build-tools 34）と JDK 17 がある環境で:

```bash
./build.sh
```

`output/apple-juice-lab.apk`（デバッグ署名）が生成されます。対象は Android 8.0（API 26）以降です。

フレームワーク不使用の純粋な Java（Android 標準 API のみ）で書かれており、Gradle なしで `javac` → `d8` → `aapt2` → `apksigner` でビルドします。
